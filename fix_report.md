Прямое клонирование в этом контейнере заблокировано DNS (`Could not resolve host: github.com`); для локального запуска исходная версия восстановлена по GitHub Raw-содержимому файлов. Локально восстановленный код воспроизводит опубликованную логику и первичную ошибку в той же строке. Исправленный архив — локальная копия, не коммит в GitHub.

## 1. Первый запуск до исправлений

**Команда:** `python3 main.py` из каталога с исходными `main.py` и `tictactoe.py`. В программу при этом не нужно ничего вводить, так как сбой происходит до первого запроса.

**Версия:** `Python 3.13.5`.

**Фактический результат:** процесс завершился с **exit code 1**:

```text
Traceback (most recent call last):
  File ".../main.py", line 4, in <module>
    run_game()
  File ".../tictactoe.py", line 76, in run_game
    player1_symbol, player2_symbol = players
TypeError: cannot unpack non-iterable function object
```

**Место:** `tictactoe.py:76` (вызов из `main.py:4`). **Причина:** `players` — объект функции; для получения кортежа двух символов нужно *вызвать* её как `players()` и возвращать символы через `return`. Скриншот ошибки: [`screenshots/01_initial_error.png`](screenshots/01_initial_error.png). 

## 2. Найденные ошибки и исправления

Номера ниже относятся к **оригинальной** версии `tictactoe.py` на GitHub, до изменения строк.

| № | Исходное место | Что было неправильно | Что изменено | Почему работает |
|---|---|---|---|---|
| 1 | `tictactoe.py:76` | `player1_symbol, player2_symbol = players`: попытка распаковать функцию | Использован вызов `players()` | Запускается запрос выбора, а распаковывается возвращаемый кортеж |
| 2 | `tictactoe.py:14` | `int(input(...))` вызывает `ValueError` для букв `X` и `O` | Ввод читается как строка, нормализуется `strip().upper()` | Символы можно сравнить со строками `"X"` и `"O"` без преобразования в число |
| 3 | `tictactoe.py:13–22` | Даже при допустимом выборе функция не делала `return` и бесконечно повторяла цикл | Вернуть пару `("X", "O")` либо `("O", "X")`; перепросить только некорректный ввод | Оба символа определены, а цикл выбора корректно завершается |
| 4 | `tictactoe.py:89` | В ветке `else` стояло сравнение `current_symbol == player1_symbol`, дающее `bool` вместо `"X"`/`"O"` | `current_symbol = player2_symbol if ... else player1_symbol` | Очередной ход всегда получает корректный символ другого игрока |
| 5 | `tictactoe.py:77–89` | `display(grid)` вызывается *перед* очередным вводом, после последнего хода показывается только в конце партии | Вывести поле перед первым ходом и после **каждого** принятого хода | Изображение поля обновляется непосредственно после каждого хода |
| 6 | `tictactoe.py:23–26` | Выводились Python-списки вместо понятной сетки | Добавлен печатный формат `1 | 2 | 3` с разделителями | Позиции от 1 до 9 визуально соответствуют клеткам |
| 7 | `tictactoe.py:31–41`, `58–66` | Невозможен явный выход посреди партии; подтверждения повторной игры распознавались непоследовательно | `Q` при любом приглашении; `Y/YES`, `N/NO` без учёта регистра/пробелов; обработка EOF и `Ctrl+C` | Можно выйти в любой момент; неверный ввод не прекращает игру |
| 8 | `tictactoe.py:55–56` | Проверка ничьей учитывала только заполненность поля, даже если там есть выигрышная линия | `draw()` дополнительно исключает победу `X` и `O` | Ничья означает **полное поле без победителя** даже при прямом вызове функции |
| 9 | `README.md:26–27, 31` | Неправильный Git URL/название папки, неоднозначная команда запуска | Исправлена инструкция, описаны Python, ZIP и рабочий каталог | Новый студент может следовать инструкции без просмотра кода |
| 10 | `README.md:5`, другие разделы | Ссылка на отсутствующий GIF, не хватает диагностики и структуры | Добавлены структура, правила, неполадки и новые материалы `docs/` | Документация самодостаточна для исправленного архива |

## 3. Запуск после исправлений

Выполнены **реальные запуски** команды `python3 main.py` с последовательностями ввода в терминале/через стандартный ввод; все завершились с **кодом 0**:

| Сценарий | Ввод (в указанном порядке) | Результат |
|---|---|---|
| Победа X | `X`, `1`, `4`, `2`, `5`, `3`, `N` | `Player 1 (X) wins!` |
| Победа O | `O`, `1`, `4`, `2`, `5`, `3`, `N` | `Player 1 (O) wins!` |
| Ничья | `X`, `1`, `2`, `3`, `5`, `4`, `6`, `8`, `7`, `9`, `N` | `The game is a draw!` |
| Повторная игра | `X`, `1`, `4`, `2`, `5`, `3`, `Y`, `O`, `1`, `4`, `2`, `5`, `3`, `N` | Две победы, поле сбрасывается, финальное `Thanks for playing!` |

Тесты проверяют выбор `X`/`O`, победу обоих игроков, все восемь выигрышных линий, ничью, повторную игру, валидацию, `Q`, EOF и обновление поля после каждого хода.
