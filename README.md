# Крестики-нолики — Tic Tac Toe (Python, терминал)

## Описание проекта

Консольная игра «Крестики-нолики» для **двух игроков за одним компьютером**. Игрок 1 выбирает `X` или `O`, игрок 2 получает другой символ. После каждого хода поле обновляется. Программа сообщает о победе или ничьей и предлагает сыграть заново. Компьютерного соперника и графического интерфейса нет.

## Требования

- **Python 3.8 или новее** (в качестве проверенной среды использовался Python **3.13.5**).
- Терминал (Windows PowerShell/Command Prompt, macOS Terminal или Linux shell).
- Git — только для установки через `git clone`; для скачанного ZIP не нужен.
- Внешние библиотеки, `pip install` и подключение к интернету **для самой игры** не требуются.

Проверьте Python:

```bash
python3 --version
```

На Windows, если `python3` недоступен, попробуйте `py --version` и команды ниже с `py` вместо `python3`.

## Установка

**Способ 1 — Git** (точный адрес исходного проекта):

```bash
git clone https://github.com/ERYXGF/tictactoe_python.git
cd tictactoe_python
```

**Способ 2 — ZIP:** откройте <https://github.com/ERYXGF/tictactoe_python>, выберите **Code → Download ZIP**, распакуйте архив и перейдите в папку, где находится `main.py`. Если у вас **исправленный ZIP, приложенный к аудиту**, распакуйте его и откройте папку `tictactoe_python`.

> **Важно:** на момент аудита оригинальный репозиторий по ссылке выше содержит ошибки. Для гарантированно рабочего запуска используйте *исправленный архив* из результатов этой работы либо перенесите исправленные `main.py` и `tictactoe.py` в клонированную папку. Команда `git clone` сама по себе скачивает **оригинальную**, не исправленную версию, пока изменения не опубликованы автором на GitHub.

## Запуск

Откройте терминал в каталоге, который содержит `main.py`, и выполните:

```bash
python3 main.py
```

На Windows возможен вариант:

```powershell
py main.py
```

Пример начала игры:

```text
Tic Tac Toe — two players. Enter Q at any prompt to quit.

Player 1, choose X or O (Q to quit): X
Player 1 is X; Player 2 is O.
 1 | 2 | 3
---+---+---
 4 | 5 | 6
---+---+---
 7 | 8 | 9

Player X, choose a position (1-9, Q to quit): 5
 1 | 2 | 3
---+---+---
 4 | X | 6
---+---+---
 7 | 8 | 9
```

Поле из цифр показывает свободные клетки. Ввод `X`/`O` и `Y`/`N` нечувствителен к регистру.

## Правила игры

- Игрок 1 выбирает `X` или `O`. Игрок 1 делает первый ход, независимо от выбранного символа.
- Игроки по очереди вводят **число от 1 до 9**, соответствующее клетке:

  ```text
   1 | 2 | 3
  ---+---+---
   4 | 5 | 6
  ---+---+---
   7 | 8 | 9
  ```

- Нельзя занять уже занятую клетку; неверный ввод вызывает повторный запрос.
- Три одинаковых символа **по горизонтали, вертикали или диагонали** означают победу. Если все клетки заполнены без победителя — ничья.
- После партии ответьте `Y` (новая игра с пустым полем и новым выбором символа) или `N` (выход).
- Наберите `Q` при **любом запросе**, чтобы завершить игру; `Ctrl+C` также завершает программу.

## Возможные проблемы

| Проблема | Решение |
|---|---|
| `python3: command not found` / «Python не найден» | Установите Python 3.8+; на Windows попробуйте `py main.py`. |
| `can't open file 'main.py'` | Перейдите через `cd` в папку с `main.py`; проверьте `dir` (Windows) или `ls` (macOS/Linux). |
| `ModuleNotFoundError: No module named 'tictactoe'` | Убедитесь, что `main.py` и `tictactoe.py` лежат **в одной папке**. |
| `TypeError: cannot unpack non-iterable function object` | Запущена **старая версия** из GitHub. Используйте исправленный архив. |
| `Please enter a whole number ...` | Для хода введите целое число 1–9. |
| `That position is already taken.` | Выберите другую свободную клетку. |
| Игра прекратилась после `Ctrl+C`/конца ввода | Ожидаемое поведение; запустите `python3 main.py` заново. |
