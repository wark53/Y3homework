# Установка и первый запуск

## Шаги

1. Установите Python версии **3.8+**. Проверка: `python3 --version` (Windows: `py --version`).
2. Получите **исправленную версию** из ZIP, прилагаемого к аудиту, и распакуйте её. Если нужно посмотреть оригинал, используйте `git clone https://github.com/ERYXGF/tictactoe_python.git` — он **не содержит исправлений** до их публикации владельцем.
3. Откройте терминал внутри папки `tictactoe_python`, где находится `main.py`.
4. Запустите `python3 main.py` (Windows: `py main.py`).
5. Введите `X` или `O`, затем числа свободных клеток от 1 до 9.

Устанавливать зависимости через `pip` не нужно. Для проверки найдите в каталоге файлы `main.py` и `tictactoe.py` командой `ls` или `dir`.

## Проверка установки

При исправном запуске появится строка `Player 1, choose X or O (Q to quit):`. Для немедленного выхода введите `Q`. Для автоматического тестирования используйте `python3 -m unittest discover -s tests -v`.

Подробнее см. [README](../README.md) и [устранение проблем](troubleshooting.md).
