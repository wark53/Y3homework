# Тестирование игры

## Автоматическая проверка

Откройте терминал в корне исправленного проекта, где лежит `main.py`:

```bash
python3 --version
python3 -m unittest discover -s tests -v
```

Ожидаемый результат: все тесты имеют статус `ok`, в конце `OK`. Тесты используют только стандартную библиотеку `unittest`.

## Ручная проверка

1. Запустите `python3 main.py` и выберите `X`. Должно появиться пустое нумерованное поле.
2. Введите последовательность `1`, `4`, `2`, `5`, `3` — получаем победу игрока 1 (X).
3. При `Play again?` введите `Y`, выберите `O`, повторите `1`, `4`, `2`, `5`, `3` — победа игрока 1 (O), значит выбор символов работает. Введите `N` для завершения.
4. Проверьте ничью: `X`, затем ходы `1, 2, 3, 5, 4, 6, 8, 7, 9`, затем `N` — сообщение `The game is a draw!`.
5. Проверьте неверный ввод: введите `cat`, `0`, `10` и занятую клетку — программа должна запросить другой ход.
6. Проверьте `Q` на выборе символа и во время партии — выход без трассировки исключения.
