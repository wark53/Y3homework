# Диагностика и решение проблем

| Сообщение/симптом | Возможная причина | Что делать |
|---|---|---|
| `python3: command not found` / `python3 is not recognized` | Python не установлен или отсутствует в PATH | Установить Python 3.8+ и проверить `python3 --version`; Windows: попробовать `py main.py` |
| `can't open file 'main.py'` | Терминал открыт не в папке проекта | Выполнить `cd` в каталог, содержащий `main.py`, проверить через `ls`/`dir` |
| `No module named 'tictactoe'` | Нет `tictactoe.py` рядом с `main.py` | Восстановить оба файла из исправленного архива |
| `TypeError: cannot unpack non-iterable function object` | Используется исходная версия, где `players` не вызывается | Взять исправленный `tictactoe.py` из архива; исходный GitHub до публикации патча не исправлен |
| `ValueError: invalid literal for int() with base 10: 'X'` | Запущен старый исходный код с `int(input(...))` | Заменить на исправленный файл; правильная версия принимает текстовый `X` или `O` |
| `Please choose X or O` | Введён другой символ | Ввести `X`, `O` или `Q` |
| `Please enter a whole number from 1 to 9` | Введено нецелое число | Ввести `1`–`9` без дополнительных символов |
| `That position is outside the range 1-9` | Введено число вне поля | Ввести число `1`–`9` |
| `That position is already taken` | Клетка уже занята | Ввести номер свободной клетки |
| Игра заканчивается после `Ctrl+C` или закрытия потока ввода | Прерван ввод | Это штатный выход; запустить команду снова |

Интернет нужен только при скачивании проекта. У игры нет внешних зависимостей. См. [установку](installation.md) и [правила](gameplay.md).
