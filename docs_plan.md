# План дополнительной документации

Цель — чтобы студент без чтения исходников мог установить, запустить и проверить игру. Четыре запланированных файла **уже созданы в этой поставке**; ниже зафиксирован их объём и возможное дальнейшее развитие.

| Файл | Содержание | Статус / дальнейшее улучшение |
|---|---|---|
| `docs/installation.md` | Python, способы получения проекта, переход в каталог, запуск, проверка версии | Создан; впоследствии добавить снимки процесса установки на Windows/macOS |
| `docs/gameplay.md` | Раскладка номеров 1–9, очередность ходов, победа/ничья, выход, новая партия | Создан; добавить GIF полного раунда после публикации файла |
| `docs/troubleshooting.md` | Ошибки Python, неверный каталог, исходный `TypeError`, ввод и занятые клетки | Создан; расширять по сообщениям новых пользователей |
| `docs/testing.md` | Команда `unittest`, ручные сценарии победы, ничьей, повторной игры, обработка ввода | Создан; добавить CI-тестирование на Python 3.8–3.13 |

Рекомендуемый порядок дальнейших работ: (1) проверить инструкцию на чистой системе Windows, (2) получить обратную связь от студента, не знакомого с кодом, (3) добавить иллюстрации и команду тестов в GitHub Actions, (4) обновлять описание ошибок по мере появления новых случаев.
